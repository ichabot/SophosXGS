# Vorlage für neue Tools

1. Ordner kopieren: `tools/_template` → `tools/<tool-name>` (Kleinbuchstaben, Bindestriche)
2. Skript umbenennen nach `Invoke-Xgs<Name>.ps1`
3. Diese README durch eine Tool-Beschreibung ersetzen (Zweck, Parameter, Beispiele)
4. Beispiel-Eingabedaten als `*.example.csv` ablegen, echte Daten bleiben per `.gitignore` lokal
5. Tool in der Übersicht der Haupt-README eintragen
